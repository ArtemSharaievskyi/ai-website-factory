# AI provider security

`OPENAI_API_KEY` is server-only and must never use a `NEXT_PUBLIC_` name. Prompts are bounded role context, never full repositories, secrets, or hidden reasoning. Safe events contain provider/model/role/prompt-version/request-id/status, typed reasoning effort where applicable, and timing metadata only; raw prompts, responses, credentials, image base64, image bytes, and chain of thought are excluded. OpenAI generation has no Factory-imposed time limit, while explicit cancellation remains mandatory for user, run, and shutdown cancellation paths.

Generated-image provenance stores only bounded project/asset metadata, the Flare family and resolved snapshot, provider request identity, prompt-contract version, requested/actual format and dimensions, checksum, byte size, retry count, and usage/cost when reported. Missing usage or cost is represented as unavailable rather than zero. Generated bytes are written only through the existing project-scoped asset pipeline.
