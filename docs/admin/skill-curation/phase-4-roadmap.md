# External skill rollout roadmap

## Phase 4B2 — curated reviewer activation

Completed by the explicit approval action recorded in the local Approved Skills Registry:

- approve and promote exactly three existing checksum-bound candidates;
- assign only the Architecture, Contract, and Security reviewers;
- resolve zero, one, or multiple relevant approved procedures without a fixed one-skill/top-K quota;
- preserve registry role/task/tool authority, immutable copies, context budgets, prompt boundaries, and reviewer staleness identity;
- leave Code / Integration, Test / Quality, Lead, Planner, Design, and Implementation skill allowlists unchanged.

## Phase 4C — future decision

Evaluate whether the remaining reviewers need additional curated procedures. Any future assignment requires a new explicit approval, exact source checksum, evidence record, role/task/tool narrowing, immutable promotion, catalog update, resolver applicability metadata, focused tests, and documentation. No discovery or approval is implied by this roadmap.
